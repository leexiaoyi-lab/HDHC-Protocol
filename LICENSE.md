- Source code and scripts: **Apache License 2.0**.

SPDX identifiers:

- `CC-BY-4.0`
- `Apache-2.0`

This dual-license choice is intended to allow broad commercial and research use while retaining attribution for the protocol and benchmark work.

## Optional future choice

If the maintainers decide that maximum frictionless adoption matters more than attribution, the text/data portion can be considered for a future **CC0** release. That decision should be made deliberately before broad third-party contributions are merged.

This file is a project licensing choice, not legal advice. Before a high-stakes institutional release, obtain appropriate legal review.
