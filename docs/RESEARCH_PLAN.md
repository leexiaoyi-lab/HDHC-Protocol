# HDHC Research Plan

## Phase 0 — v0.1 package

Goal: create a coherent protocol and 50 adversarial cases before public advocacy.

## Phase 1 — Internal falsification

- Run all 50 cases under baseline and HDHC-guided conditions.
- Blind-score outputs.
- Identify dimensions with no improvement or regression.
- Rewrite ambiguous rules only when failure cases justify it.

## Phase 2 — External red team

Invite researchers and practitioners to submit cases designed to break:

- victim-first ordering;
- return paths;
- minimum-intervention reasoning;
- evidence thresholds;
- reversibility;
- power symmetry;
- anti-greater-good safeguards.

Target: 150+ cases before v0.5.

## Phase 3 — Cross-model benchmark

Run multiple frontier and open-weight models under the same protocol.

Report:

- aggregate score;
- per-dimension score;
- under-containment / over-intervention rates;
- automatic failure flags;
- evaluator disagreement;
- model-specific regression cases.

## Phase 4 — Domain-specific subsets

Only after the general framework is stable enough, build subsets for:

- workplace governance;
- schools and youth settings;
- online platforms;
- AI agent permissions;
- organizational security;
- public-sector decision support.

Do not market domain-specific guidance as professional legal/clinical policy without domain validation.

## Phase 5 — v1.0 gate

A v1.0 candidate should require:

- external contributors;
- documented counterexamples;
- cross-model data;
- transparent negative results;
- stable definitions with acceptable evaluator agreement;
- evidence that HDHC improves more than rhetoric or answer length.
