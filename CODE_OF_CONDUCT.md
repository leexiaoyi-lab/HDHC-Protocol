# Code of Conduct

This project welcomes rigorous disagreement.

Expected:

- critique claims with reasons and evidence;
- steelman opposing views where possible;
- separate people from harmful behavior;
- avoid harassment, threats, humiliation, and identity-based attacks;
- do not publish private personal information;
- report concrete project-safety concerns through the misuse-report issue template.

Unacceptable:

- threats or celebration of real-world harm;
- targeted harassment;
- doxxing;
- using the repository to organize retaliation against real people;
- knowingly fabricated evidence.

Moderation should use the minimum intervention sufficient to protect the community, with review paths where safe and practical.
